# カコモと学ぶ 決算チャレンジ 議会費編

加古川市 令和7年度決算のうち「議会費」(決算総額 約5億2,496万円)を題材にした、クイズ+予算判断シミュレーションのPWAです。

## 構成

- `index.html` — 本体(単一HTMLファイル、データはJSONとしてページ内に埋め込み済み)
- `manifest.json` — PWAマニフェスト
- `sw.js` — オフラインキャッシュ用の最小限のService Worker
- `icon-192.png` / `icon-512.png` / `apple-touch-icon.png` — アイコン(款名の文言なし、全款共通)
- `og-image.png` — SNSシェア用画像(議会費版、本款専用)

## この款の特徴

議会費は、他の款と違って主要な施策の成果(事業報告書)側に評価対象の「事業」が1件もありません(公債費と同じパターン)。そのため本編シミュレーションは、款全体を以下の2枚の簡易カードで構成しています。

1. **議員報酬・議会事務局職員人件費**(決算額の約91.4%): 議員30人の報酬、議会事務局職員の給料・手当・共済費
2. **議会運営に関する経費(政務活動費・委託料など)**(決算額の約8.6%): 会派への政務活動費(合計約1,676万円)、会議録作成・議会中継等の委託料、タブレット端末・ペーパーレス会議システムの使用料、議長会等への負担金

いずれも地方自治法・条例に基づく支出のため、2枚とも「法定給付(市に減額・裁量の余地がない)」に分類しています。

## 内容

- **①入口クイズ**: 全12問(基礎知識5問+予算vs決算2問+特別トリビア5問)、全問2択形式
- **②本編シミュレーション**: 上記2枚のカードで増額・維持・減額・廃止を判断(法定givのため実際の影響額には反映されません)
- **③答え合わせ**: 議事録公開待ちのため未実装

## 「資料の限界」トリビアについて

タブレット端末・ペーパーレス会議システムの費用対効果や必要性は、決算書の数字だけでは判断できないという点を特別トリビアの1問として採用しています。実際に情報公開請求で確認された事情として、タブレット端末のリース単価は相場としては高めであること、操作が難しい議員がいる一方で個人端末を持ち込む議員もいること、ペーパーレス化がランニングコストの面では紙より高くつく面があることなどが、決算書やAIによる分析だけでは見えてこない実情としてあります(具体的な単価・詳細はこのアプリには含めていません)。

## 公開時の作業

`index.html`冒頭のOGP用URL(`kessan-challenge/gikai/`の部分)を、実際の公開先パスに合わせて書き換えてください。
